Resolves #877

**What changed?**
Replaced hardcoded light-theme colors in the `ExportOverlay` component with theme-aware CSS variables. 
- The background `bg-white/95` was changed to `bg-[var(--bg)]/95`.
- The "Cancel Export" button was updated to use the `--error`, `--error-bg`, `--error-border`, and `--error-hover` CSS variables defined in `globals.css` instead of hardcoded `red-50` / `red-600` classes.

**Why?**
As mentioned in the issue, the hardcoded white overlay caused a glaring bright flash when the app was running in dark mode. The new theme-aware variables ensure the overlay and its buttons automatically respect the user's active theme while keeping the UI consistent and avoiding visual disruption during export.
