# Contributing to Reframe

## Setup
```bash
# Fork the repo, then clone it:
git clone https://github.com/YOUR-USERNAME/reframe.git
cd reframe

# Install dependencies and run dev server
bun install
bun dev
```

## Guidelines
- Write clean, consistent code.
- Test your changes locally.

## Submitting a PR
1. `git checkout -b feature-branch`
2. Commit your changes.
3. `git push origin feature-branch`
4. Open a Pull Request.

## Issues
Check our [Issue Tracker](https://github.com/magic-peach/reframe/issues) for bugs and feature requests.
